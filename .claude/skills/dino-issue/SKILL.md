# 이슈와 라벨

원본: [이슈 양식·작성](references/forms.md), [라벨](references/labels.md), [유형](../dino-commit/references/change-types.md).

- 유형 하나를 목적 기준으로 고르고 그에 맞는 `.github/ISSUE_TEMPLATE` 양식을 씁니다. 라벨은 `type:<유형>` 하나에 필요한 `area:*`를 더합니다.
- 기능 이슈는 노션 정책서·기능명세 링크와 절을 적고 명세를 복사하지 않습니다. 완료 조건은 노션 수용 기준을 가리킵니다.
- 관찰 사실과 원인 가설을 구분하고, 모르는 것은 `미확인`으로 적습니다. 비밀값·개인정보를 제거합니다.
- 작성 전에 같은 문제를 다룬 이슈가 있는지 확인합니다. 요청한 이슈 생성·수정·댓글은 추가 확인 없이 수행합니다.
