# DB 자원 승인

DB 삭제·컨테이너 검사·스키마 삭제 앱 실행 시 [공통 승인](../../../../AGENTS.md#approvals)을 적용합니다. 테스트 전용 자원과 앱 내부 자동 삭제도 포함합니다.

| 행위 | 실행 전 요약 |
| --- | --- |
| 데이터·볼륨 삭제 | 환경·DB/볼륨 식별자·삭제 범위·복구 가능 여부 |
| DB·컨테이너 검사 | 명령·대상 테스트·테스트 DB 생성·데이터/컨테이너/볼륨 정리 범위 |
| 스키마 삭제 앱 | 명령·활성 프로필·대상 DB·시작/종료 시 스키마 생성·삭제 범위 |

검사 전체 생명주기를 승인받으며 개별 삭제 SQL마다 멈출 수 있다고 가정하지 않습니다. 반복할 횟수·조건도 요약하고 승인 범위를 넘으면 다시 확인합니다. 승인 전에는 DB 삭제 없는 독립 검사를 수행하고 나머지를 미검증으로 보고합니다.

[빠른 시작](../../../../README.md#빠른-시작)의 `./gradlew bootRun`은 기동 시 대상 DB에 미적용 마이그레이션을 적용하고 스키마를 지우지 않습니다. 대상 DB가 로컬 Compose DB가 아니면 실행 전에 대상과 적용될 버전을 요약해 승인받습니다. 로컬 DB를 초기화하는 볼륨 삭제는 데이터·볼륨 삭제 승인 대상입니다.
