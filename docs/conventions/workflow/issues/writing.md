# 이슈 작성

이슈 초안·작성 요청 시 [유형](../change-types.md#change-types)·[양식](forms.md#forms)·[라벨](../labels.md#labels)을 적용합니다. AI 작성은 [공통 게시 절차](../publishing.md#publishing)를 따릅니다.

- 제목은 대상·문제 또는 원하는 결과를 한 문장으로 적습니다. 유형은 라벨로 구분하며 제목 접두사를 강제하지 않습니다.
- 작성 전 관련 이슈를 확인하고 같은 문제면 기존 이슈에 근거를 보탭니다. 접근하지 못했으면 중복 확인 완료로 보고하지 않습니다.
- 관찰 사실·원인 가설을 구분합니다. 완료 조건은 결과로 확인할 수 있게 쓰고, 조사에는 답할 질문·종료 조건을 둡니다.
- `perf`는 기준선·측정 조건, `revert`는 대상 PR/커밋·복구 조건을 적습니다. 공용 필드라 웹에서 유형별 필수 입력을 강제하지 않으므로 분류 때 누락을 확인합니다. 미측정이면 수치 대신 그 사실·계획을 적습니다.
- 필수 항목은 채우고 무관한 선택 항목은 비웁니다. 모르는 사실은 `미확인`으로 표시합니다. 로그·요청·화면은 필요한 부분만 첨부하고 실제 비밀값·개인정보를 제거합니다.

조사 결론은 이슈에, 확정된 구조·정책은 관련 컨벤션·해당 ADR에 반영합니다. 독립 주제의 ADR 추가는 [문서 관리](../../../agents/documents/maintenance.md#maintenance)를 따르고 [ADR 색인](../../../adr/README.md)도 맞춥니다. 코드·상시 문서 변경이 없으면 PR 없이 이슈에서 마칩니다.
