# 트러블슈팅

반복 조사에서 얻은 재사용 가능한 문제 해결 지식을 보관합니다. 오류·실패 조사 시 아래 색인에서 관련 사례만 확인합니다. 자동 기록 조건과 시점은 [루트 지침](../../AGENTS.md)을 따릅니다.

## 기록 규칙

- 다음 조사에서 같은 시행착오를 줄일 수 있는 내용만 문제별로 기록합니다. 단순 오타·일회성 실행 실패·대화 및 실행 이력은 제외합니다.
- 기존 사례가 있으면 갱신하고, 새 사례는 증상으로 식별할 수 있는 파일명으로 작성하여 아래 색인에 연결합니다.
- 증상·발생 조건, 원인과 근거, 해결·검증을 적습니다. 실패한 접근은 재시도를 피할 근거가 있을 때만 남깁니다.
- 미해결이면 사실과 가설을 구분하고 다음 확인 사항을 적습니다. 비밀값은 제외하고, 상시 규칙은 기존 컨벤션·ADR을 링크합니다.
